# Taller Integrador — IA aplicada a procesos empresariales
## Empresa: Mentea (salud mental) · Canal: chat web

Documentación del taller, basada en el agente conversacional real implementado en este repositorio (`mentea-web1.2`). Todos los datos (prompt, base de conocimiento, flujo, reglas de crisis/escalado) provienen del prototipo funcional, no son inventados.

## Notas

- **Actividad 7 (prototipo):** es el propio agente de este repositorio (ver `docs/CHAT_AGENT.md`). Para probarlo: iniciar sesión como `paciente@mentea.test` / `password` y usar el widget de chat.
- **Seguridad:** ningún documento incluye contraseñas, tokens ni claves API (requisito del taller y buena práctica).
- **Pendiente de completar por el equipo:** nombres de los integrantes (portada del informe), capturas de pantalla (sección 7 del informe) y la grabación del video.
